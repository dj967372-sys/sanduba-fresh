## Funcionalidades do Site
- **Catálogo Oficial:** Filtros e busca por nome ou descrição.
- **Carrinho de Compras:** Adição/remoção de itens, cálculo de subtotal e total em tempo real.
- **Checkout Inteligente via WhatsApp:** Envio direto do pedido formatado com a chave Pix oficial e confirmação do termo de retirada combinada.
- **Mini Jogo Interativo (Desafio da Memória):** Jogo divertido para os clientes encontrarem os pares de ingredientes frescos antes que o tempo acabe.
- **Avaliações com Estrelas:** Sistema para os clientes enviarem suas notas (1 a 5 estrelas), comentários ou sugestões de novos sabores.
- **Painel Administrativo:** Acesso restrito por senha (`admin123`) para alternar a disponibilidade dos produtos e conferir a chave Pix configurada.
- **Tema Claro/Escuro:** Suporte a alternância de temas para melhor usabilidade.

## Tecnologias Utilizadas

## Como Executar Localmente pelo VS Code
1. Abra a pasta do projeto no **VS Code**.
2. Certifique-se de que os arquivos `index.html`, `style.css`, `script.js` e `README.md` estão salvos na mesma pasta.
3. Instale a extensão **Live Server** no VS Code.
4. Clique com o botão direito sobre o arquivo `index.html` e selecione **Open with Live Server**.
5. Acesse pelo navegador para testar todas as funcionalidades do site!
